<h1>Active Directory Homelab</h1>



<h2>Description</h2>
A small Active Directory homelab designed to simulate a real-world Windows domain environment. It includes a Windows Server domain controller for managing users, groups, DNS, DHCP, and Group Policy, along with Windows client machines joined to the domain. The lab provides a safe environment for practicing Active Directory administration, authentication, permissions, security policies, and troubleshooting.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>Diskpart</b>

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
